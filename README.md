# ✨ GLOW PRESTIGE - Nền Tảng Đặt Lịch & Quản Lý Làm Đẹp Thượng Lưu

> **Dự án Marketplace kết nối khách hàng với salon, tiệm nail, spa cao cấp.**  
> Tích hợp 3 phân hệ vai trò: **Khách hàng (Customer)**, **Đối tác (Salon Partner)**, và **Quản trị viên (Admin Moderation)**.

---

## 🌟 Tính Năng Cốt Lõi

### 1. 👤 Phân Hệ Khách Hàng (Customer Hub)
* **Khám phá dịch vụ theo danh mục:** Nail Art, Spa Trị Liệu, Chăm sóc da, Đặt lịch VIP, Hair Salon, Makeup Tiệc, Dưỡng sinh Đông Y.
* **Tìm kiếm thời gian thực (Live Search):** Tìm nhanh theo tên salon, dịch vụ hoặc khu vực/quận kèm nút xóa nhanh `(x)`.
* **Đặt lịch Combo nhiều dịch vụ cùng lúc:** Tự động cộng dồn thời lượng dự kiến (`⏱ phút`) và tự động tính cọc `30%` trên tổng hóa đơn.
* **Đồng hồ đếm ngược 10 phút (Hold Slot Timer):** Tạm giữ khung giờ thực tế chống đặt ảo.
* **Cổng thanh toán cọc đa kênh:** VietQR / Ngân hàng, Ví MoMo Sandbox, Ví GlowPrivé.
* **Quản lý vé booking & Mã QR Check-in VIP:** Nhắc lịch hẹn tự động trước giờ hẹn.
* **Chính sách hủy & hoàn cọc tự động:** Hoàn 100% tiền cọc về Ví nếu hủy trước ≥ 2 tiếng.
* **Đánh giá sau dịch vụ 5 sao:** Tích lũy GlowXu thưởng.

### 2. 🏪 Phân Hệ Salon Đối Tác (Partner Portal)
* **Lịch Hoạt Động (7 Ngày x Khung Giờ):** Xem trạng thái toàn bộ tuần, chạm 1 chạm để **Khóa/Mở slot nhận khách** tức thì.
* **Menu Dịch Vụ & Bảng Giá Niêm Yết:** Quản lý danh mục, giá dịch vụ và tỷ lệ đặt cọc 30%.
* **Gói Đối Tác & Sponsored Listing:** Starter (Miễn phí), Pro Partner (499k/tháng), VIP Sponsored Lounge (999k/tháng).

### 3. 🛡️ Phân Hệ Quản Trị Hệ Thống (Admin Marketplace)
* **Duyệt hồ sơ cơ sở mới:** Xem thông tin, giấy phép kinh doanh, duyệt **Kích hoạt** hoặc **Từ chối**.
* **Kiểm duyệt đánh giá (Review Moderation):** Quản lý đánh giá khách hàng, ẩn các review vi phạm hoặc spam link.
* **Bảng thống kê sàn:** Theo dõi số lượng đối tác Active, hồ sơ chờ duyệt và tổng tiền cọc giữ sàn.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Trực Tiếp

Dự án sử dụng HTML5, CSS3 và Vanilla JavaScript thuần (không phụ thuộc build tool phức tạp).

```bash
# Clone repository về máy
git clone https://github.com/Tuan133/app-lam-dep.git

# Mở thư mục dự án
cd app-lam-dep

# Chạy server cục bộ bằng Python
python -m http.server 3000
```

Mở trình duyệt truy cập: **`http://localhost:3000`**
